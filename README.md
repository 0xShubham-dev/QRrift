# 📱 QRift 💻

**Bridge devices. Not servers.**

QRift is a lightweight, privacy-first tool designed to instantly transfer text, code snippets, and URLs between devices using QR codes. No accounts, no cloud sync, and no server-side storage.

## Features

- **Frictionless Transfer:** Instantly convert long strings and code into QR codes, or scan to retrieve text.
- **Privacy-Focused:** 100% local text processing. Your data never leaves your screens.
- **Offline Capable:** Works without an internet connection once loaded.
- **Dev-Friendly:** Perfect for moving debugging info, URLs, and config strings across devices.

## How It Works

1. Open **QRift** on your sending device.
2. Enter or paste your text.
3. Generate the QR code.
4. Scan it with the receiving device to retrieve the payload.

> **🔒 Security Note:** While QRift doesn't store data, avoid encoding highly sensitive information (like passwords) that could be easily photographed by bystanders.
